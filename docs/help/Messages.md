# Messages

Everything the editor has said this session: why an edit was refused, save and pack results, and reports from conversions. The newest is first, each with a time and a severity (info, warning or error).

**Open it from:** click the message bar at the bottom of Chart Builder, or **View**, then **Messages**.

## What's In It

- A search box, the list of messages, and a detail pane for the selected one.
- **Copy** and **Close**.

It keeps the last 200 messages, for this session only.
