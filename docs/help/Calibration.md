# Calibration

Measures the delay between what's played and what you see or hit, so notes line up with the sound. It has two modes.

## Calibrate Audio Latency

**Open it from:** [Settings](Settings.md), then Playback, Audio, then **Calibrate…** (in either app), or Chart Builder's latency button.

A highway with clicks plays. Adjust **Latency** until each click matches a note hitting the strike line. **Tap along** lets you tap with the clicks instead. Holding Space draws the notes uncalibrated for comparison. **Reset to 0**, **Save** and **Cancel**.

## Calibrate Input Device

**Open it from:** Chart Builder's [Input Devices](Input-Devices.md) window, **Calibrate…**.

There is no sound. Hit the device along with the notes to calculate the offset. **Start**, **Try again**, **Save** and **Cancel**.

The audio latency is stored in a file shared by both apps. Input device offsets are used by Chart Builder only. Closing without saving leaves them unchanged.
