# Calibration

Measures the delay between what's played and what you see or hit, so notes line up with the sound. It has two modes.

## Calibrate Audio Latency

**Open it from:** [Settings](Settings.md), then Playback, Audio, then **Calibrate…** (in either app), or Chart Builder's latency button.

A highway with clicks plays. Move **Latency** until each click matches a note hitting the strike line (arrow keys step 1 ms, or 5 ms with Shift). **Tap along** lets you tap with the clicks instead. Holding Space draws the notes uncalibrated for comparison. **Reset to 0**, **Save** and **Cancel**.

## Calibrate Input Device

**Open it from:** Chart Builder's [Input Devices](Input-Devices.md) window, **Calibrate…**.

There is no sound. Hit the device along with the notes, and it works out the offset and how much it varies. **Start**, **Try again**, **Save** and **Cancel**.

The calibrated values are stored in a file shared by both apps. Closing without saving leaves them unchanged.
