# Chart-Packer Help

Chart-Packer packs and unpacks song folders as `.sng` files for Clone Hero, YARG and other rhythm games. It installs with **Chart Builder**, a separate app for creating and editing charts.

New here? Start with [Getting Started](Getting-Started.md).

Every window has a **?** button in its title bar (or press **F1**) that opens its page below.
