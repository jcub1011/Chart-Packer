# Preview

A note highway preview of the focused lane, or a part and difficulty you choose.

**Open it from:** Chart Builder, **View**, then **Preview window**, or the **Window** button in the Preview tab. Only one can be open, and it follows the editor when another song is opened.

## What's In It

A track selector, playback options (speed, practice, look-ahead) and highway options.
