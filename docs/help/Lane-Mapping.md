# Lane Mapping

Asks where each lane of a pasted passage should land, because 5-fret and 6-fret (GHL) lanes differ.

**Open it from:** it opens by itself when you paste notes copied from a 5-fret lane into a GHL lane, or the other way round.

## What's In It

- One row per source lane, each with a drop-down of destination lanes. Open notes stay open.
- **Paste** and **Cancel**. Cancel stops the paste.
