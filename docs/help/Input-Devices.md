# Input Devices

Binds the keyboard, game controllers (guitars, drums, gamepads) and MIDI devices to frets, strum and pads, for playtest and record mode.

**Open it from:** Chart Builder, **File**, **Settings…**, then Input, then **Input devices…**. It stays open so playtest can run while it is.

## What's In It

- A list of devices with activity lights and **Rescan**. For the selected device, an input offset with **Calibrate…** ([Calibration](Calibration.md)).
- Settings for MIDI velocity (shown for MIDI devices), and quick layouts such as the General MIDI drum map and the Xbox guitar layout.
- Tabs for the 5-fret and Drums profiles. Each action has its bindings, **+ Bind** (then press a control), and a way to remove them.
- **Reset to keyboard defaults.**

By default, Space, P, N and Esc are reserved for the editor's play, playtest and cancel keys and can't be bound. They follow the editor's shortcuts if you change those.
