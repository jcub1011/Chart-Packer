# Chart Issues

Lists the findings from checking a chart, as errors, warnings and information, for you to search, filter and fix.

## How To Find It

- Chart Packer: the **View issues…** button in a song's details, which shows when the chart has findings. It opens as a window.
- Chart Builder: the same list is the Findings tab in the editor's right panel. A Findings error blocks Pack, but not Save.

## What's In It

- A search box and filters for severity, instrument, difficulty and type (timing, frets, drums, phrases and events, song, vocals, loading and other).
- Findings grouped as Errors, Warnings and Informational, with counts. In Chart Builder, findings can have fix actions.
