# Deduplicate Library

Finds duplicate songs across your whole library and moves the copies you don't need to the Recycle Bin. If Windows can't recycle a copy, you are asked before it is deleted permanently. Songs that changed since the scan, or have unsaved changes, are skipped.

**Open it from:** Chart Packer, **Tools**, then **Deduplicate…**. It rescans the library first, then compares.

## What's In It

- **Exact Duplicates:** every file and all metadata match.
- **Same Chart:** the chart matches, but metadata or files differ.
- **Merge Candidates:** the same artist and title with different charts. You can open the group in [Merge](Merge.md).
- A search box and category chips, a list of groups, and a panel showing each copy's path, kind, size and charter.
- A **Keep** or **Delete** choice per copy, plus **Delete Marked** to remove them.
