# Merge Songs

Combines several songs into one new `.sng` in the output folder. You choose which song supplies each piece.

**Open it from:** Chart Packer, **Tools**, then **Merge…** (two or more songs selected, with no scan or job running), the library's right-click menu, or **Open in Merge…** from [Deduplicate](Dedup.md).

## What's In It

Your songs sit side by side, with a live preview of the merged song at the right. Choose the source for each of:

- the base chart (tempo map and events)
- each instrument part
- audio tracks
- album art and backgrounds
- metadata (only values the songs disagree on)
- charters and the output
- alignment between songs, with **Auto-Align** and **Reset**. To line one up by eye, see [Line Up](Merge-Compare.md).

## Good to Know

- Unsaved edits aren't included in the merge.
- A source song is never overwritten.
- The merged `.sng` can't replace an existing file unless the Settings policy for existing output is set to overwrite or keep both.
