# Settings

A searchable list of settings, grouped by category. Both apps use this window, each with its own settings.

**Open it from:** **File**, then **Settings…** (Ctrl+,).

## What's in it

- A category list on the left and a search box (Ctrl+E).
- Changed settings are outlined until applied, and each has a button to reset it.
- **OK** applies and closes, **Apply** applies without closing, and **Cancel** discards.

## Chart Packer's settings

Library (scanning, duplicates), output (pack and unpack, downloads), playback (audio, visualizers, scrubbing), and general (appearance, logging).

## Chart Builder's settings

Playback (including the countdown), input (opens [Input Devices](Input-Devices.md)), default reduction rules (opens [Reduce](Reduce.md)), pack folder, and what opens on startup.
