# Settings

A searchable list of settings, grouped by category. Both apps use this window, each with its own settings.

**Open it from:** **File**, then **Settings…** (Ctrl+,).

## What's In It

- A category list on the left and a search box (Ctrl+E). **All Settings** at the top shows every category, and while you search, each category shows how many of its settings match.
- Each page names its category and the sections in it.
- A bar beside a setting, and a number beside its category, mark changes that have not been applied yet. The bottom left says how many there are.
- A setting that differs from its default has a button to reset it.
- **OK** applies and closes, **Apply** applies without closing, and **Cancel** discards.

Both this window and **Shortcuts** take on the colours of the song selected in Chart Packer, as the main window does.

## Chart Packer's Settings

Library (scanning, duplicates), output (pack and unpack, downloads), playback (audio, visualizers, scrubbing), and general (appearance, logging).

The audio section holds **Low Latency Audio**, which plays audio on Windows' low-latency audio path so it's heard sooner (on by default, applies when the app starts), **Output Device**, which chooses the device audio plays on (**Default output device** plays on the system's default device, as does a chosen device that isn't connected), and **Audio/Visual Latency**, measured per output device.

## Chart Builder's Settings

Playback (audio latency and visualizers, including **Highway length**: how far ahead a highway shows, by a look-ahead in seconds or by pixels per second, which keeps the distance between notes the same at any height; **Low Latency Audio** and **Output Device**, as in Chart Packer), input (including the playback countdown, and a link to [Input Devices](Input-Devices.md)), charter (new charts and editing, including the pack folder and the default reduction rules, which open [Reduce](Reduce.md)), and general (what opens on startup, logging, updates).
