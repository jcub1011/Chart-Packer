# Reduce

Drafts an easier difficulty from a harder one by applying rules. The draft is drawn over the target as you change the rules, and **Apply** adds it as one undoable step.

**Open it from:** a lane's Edit menu in Chart Builder, then **Reduce…**. A Findings fix for a missing lower difficulty opens it too. In [Settings](Settings.md), the "Default reduction rules" row opens it to edit the defaults.

## What's In It

- **To**, **From** and **Over** (the whole part, the selection, or the section at the cursor). To make Hard, Medium and Easy in one go, choose **Hard, Medium and Easy** in **To**.
- The rules, which differ for 5-fret, GHL and drums: chord size, spacing, bursts, and which note types to keep.
- A summary of the draft, a ladder of how hard each difficulty is, and findings for the draft.
- A **Preview** toggle that shows the source and draft highways side by side.
- **Reset**, **Apply** (**Save** when opened from Settings) and **Cancel**.

## Note

Don't accept the generated difficulties as-is. They are intended to be a starting point for charting.

The same rules are used by Chart Packer's [Generate Lower Difficulties](Lower-Difficulties.md).
