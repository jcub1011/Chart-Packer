# Line Up (Merge Compare)

Puts two songs on one timeline so you can line one up with the kept audio by eye, by dragging it sideways.

**Open it from:** the [Merge](Merge.md) window, using the waveform button on a song's header.

## What's In It

- An **Offset** box (in milliseconds) and **Jump to Link**.
- Zoom in and out, **First Notes** and **Whole Song** views. Scroll zooms, Shift+scroll moves along the song, and Ctrl+drag makes finer moves.
- **Undo** restores the offset the song had when the window opened.
- **Use This Offset** applies it to the merge. **Cancel** discards it.
