# Confirm dialogs

A small prompt that asks before something that can lose work, or tells you something. It has one or two actions and **Cancel**. Some are notices with only **OK**.

Examples are "Unsaved Changes" (save, discard or cancel), "Delete Duplicates", and "Save Invalid Metadata".

Enter or Escape chooses Cancel, so the safe choice is the default, except in notices, where either closes it.
