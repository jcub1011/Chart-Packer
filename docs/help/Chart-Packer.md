# Chart Packer

Chart Packer is used to view and manage your chart library. Once pointed at a folder of charts and scanned, it lists all `.sng` files and folders containing `song.ini` files. From there you can pack, unpack, edit metadata, play songs, and run tools across many songs at once.

## Good to Know

- Dropping a folder anywhere on the window sets the songs folder and scans it.
- Edit Chart needs Chart Builder installed.
