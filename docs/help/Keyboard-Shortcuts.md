# Keyboard Shortcuts

Lists every shortcut in the app and lets you change them. Both apps use this window, and shortcuts they have in common, such as Save, are shared.

**Open it from:** the **Edit** menu, then **Shortcuts…**.

## What's In It

- A category list and a search box. A number beside a category counts the shortcuts in it that differ from their defaults.
- For each shortcut: change it, remove it, or add an alternate. **Restore Defaults** resets one, and a bar beside it marks a change.
- **List** and **Keyboard** buttons at the top switch between the two views below.
- **Import** and **Export** (JSON files), **Reset All**, **OK** and **Cancel**. The bottom left says why a key was refused, or what an import did.

## The Keyboard View

Shows a keyboard. **Ctrl**, **Shift** and **Alt** choose which modifier keys are held, and each key is tinted by what has it in that layer: violet for a shortcut, amber where shortcuts that can be live together share it, and dimmed where every shortcut on it is fixed. Hover a key to see which shortcuts have it.

Pick a key to list what is on it. From there you can take a key off a shortcut, find the shortcut in the list, or bind another shortcut to the key. Binding works as it does in the list: a key that is already used asks whether to move it or keep both, and a key the system reserves is refused. Keys the keyboard doesn't draw, such as number pad keys, appear under **Other Keys**.

Searching returns to the list, and switching to the keyboard clears the search.

Some shortcuts, such as Undo and Redo, are fixed. A shortcut that is already used asks whether to move it or keep both. Keys the system reserves are refused.

Press **F1** in any window to open its help page.
