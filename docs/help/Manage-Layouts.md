# Manage Layouts

Layouts are saved arrangements of the Editor's lanes. A layout records which lanes are open, where each one is docked, how big it is, and each lane's own view settings (look-ahead, perspective, audio and the vocal pitch view). It doesn't include the side panels.

Loading a layout replaces the lanes that are open. Changing the lanes afterwards never changes the layout. To update a layout, overwrite it. Chart Builder starts with one layout, **Default**: Expert Guitar and Expert Drums side by side.

**Open it from:** **View → Manage Layouts…**

## The View Menu

- **View → Load Layout** lists every layout. Choose one to load it in place of the lanes that are open. If those lanes aren't already saved as a layout, Chart Builder asks first, because loading can't be undone and their arrangement would be lost.
- **View → Save Layout** lists every layout, then **New Layout…**. If you choose an existing layout, Chart Builder asks before overwriting it with the lanes that are open. **New Layout…** asks for a name and saves the lanes that are open as a new layout at the bottom of the list. It's disabled once there are 100 layouts.

## What's In It

- The list of layouts, in the order the View menu shows them.
- **New Layout** saves the lanes that are open as a new layout at the bottom of the list, after asking for its name.
- **Rename** gives the selected layout a new name.
- **Move Up** and **Move Down** change the selected layout's place in the list.
- **Overwrite Layout** replaces the selected layout with the lanes that are open, after asking first.
- **Delete** removes the selected layout, after asking first. Deleted layouts can't be restored, including **Default**.
- **Close**.

## Naming A Layout

Every layout needs a name of up to 64 characters, and no two layouts can share a name. Names that differ only in capitalization count as the same, so "Drums" and "drums" can't both exist. **Save** (or **Rename**) stays disabled until the name is allowed, and a note under the box explains what's wrong. You can have up to 100 layouts.
